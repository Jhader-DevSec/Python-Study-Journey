# 🐍 60 Dias de Programação em Python

Esta pasta faz parte do repositório principal e reúne o desafio **60 Dias de Programação em Python**.

O objetivo é reforçar o aprendizado da linguagem por meio da prática diária, desenvolvendo pequenos projetos e exercícios para consolidar os principais conceitos do Python.

---

## 🎯 Objetivo

Durante 60 dias, cada atividade aborda um conceito específico da linguagem, permitindo revisar conteúdos, desenvolver raciocínio lógico e aumentar a fixação dos conhecimentos por meio da prática contínua.

A proposta não é criar projetos completos, mas sim construir uma base sólida em Python através de exercícios curtos e objetivos.
